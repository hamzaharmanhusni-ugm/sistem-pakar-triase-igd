# Perlu ke IGD? Sistem Pakar Triase IGD

Sistem pakar triase IGD berbasis Emergency Severity Index (ESI) versi 4. Pengetahuan disimpan sebagai knowledge graph OWL/RDF, aturan IF-THEN bersumber dari pedoman ESI, penalaran berjalan dengan forward chaining, dan setiap kesimpulan disertai penjelasan.

Halaman ini menampilkan aplikasi yang berjalan di Space [Hamzaharman/sistem-pakar-triase-igd](https://huggingface.co/spaces/Hamzaharman/sistem-pakar-triase-igd). Alamat ringkasnya: https://sistempakar-triase-igd.static.hf.space

Aplikasi ini untuk tujuan pendidikan dan bukan alat diagnosis. Dalam keadaan darurat, telepon 119.

Kode sumber: https://github.com/hamzaharmanhusni-ugm/sistem-pakar-triase-igd
